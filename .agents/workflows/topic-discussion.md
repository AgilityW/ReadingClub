# 话题讨论工作流 💬

## 触发方式
```
输入：[话题/命题/问题]（可附加：背景说明、希望聚焦的角度、想挑战的观点）
```

示例：
- `人工智能会取代创意工作吗？`
- `"躺平"作为一种社会现象，意味着什么？`
- `为什么好的制度总是难以持续？`

---

## Phase 0｜参与确认
**执行者**：host
**输入**：话题 + 用户附加说明
**任务**：主理人读取 `.agents/roster.md`，向用户展示完整成员列表，由用户选择本次参与者

输出到：`shared/session.md`（记录参与成员 ID 列表）

> 详细展示格式见 `host/soul.md` Phase 0 章节。

---

## 与读书会工作流的差异

| 维度 | 读书会 | 话题讨论 |
|------|--------|---------|
| 输入 | 一本书（有具体文本） | 一个命题（开放性更强） |
| Phase 1 | 基于书的内容解读 | 基于话题自由立论 |
| 对话张力 | 来自书的内容与各视角的碰撞 | 来自各视角本身对命题的分歧 |
| 写作挑战 | 整合多视角对同一文本的解读 | 构建一个对开放命题的多维度分析 |

---

## Phase 1｜独立立论
**执行者**：本次 session 选中的读者 Agent（并行，从 `shared/session.md` 读取名单）
**输入**：话题 + 用户附加背景
**任务**：每个 Agent 从自身视角出发，对话题提出立场和论证

输出到：`shared/phase1_outputs/{agent_id}.md`

输出格式：
```markdown
## [{Agent名称}] 的立场

### 核心立场
[一句话：我对这个话题的基本判断]

### 三个支撑论点
1. [论点 + 论证]
2. [论点 + 论证]
3. [论点 + 论证]

### 我认为这个话题最容易被忽视的维度
[来自本视角的独特补充]
```

---

## Phase 2｜主理人整合
**执行者**：host
**输入**：所有 Phase 1 输出

整合重点（与读书会略有不同）：
- **立场谱系**：把各 Agent 的立场在一个坐标轴上标出（支持/反对/条件性支持/拒绝二元框架）
- **核心分歧**：找到最根本的分歧点（往往是前提假设的不同）
- **意外联盟**：找到来自不同视角的意外共识

输出到：`shared/discussion.md`

```markdown
## 🎙️ 主理人·Phase 2 整合

### 立场谱系
[绘制各 Agent 立场分布]

### 核心分歧（前提层面）
**分歧 1**：[Agent A] 的前提是……而 [Agent B] 的前提是……
这不只是结论不同，而是出发点不同。

### 意外联盟
[来自不同视角的共识，值得特别关注]

### 第一轮讨论议题
**议题 1**：[针对核心分歧的追问]
**议题 2**：[针对某个被忽视维度的展开]
```

## Phase 3｜多轮对话
流程与读书会工作流相同，参见 book-club.md Phase 3。

**话题讨论的特别要求**：
- 鼓励直接反驳（"我不同意X的说法，因为……"）
- 欢迎立场在讨论中演变（Round 2 可以修正 Phase 1 的立场，但需说明原因）
- 警惕"各说各话"——必须真正回应对方的论证，而不是重复自己的观点

---

## Phase 4｜主理人收束
与读书会工作流相同，参见 book-club.md Phase 4。

话题讨论的额外收束项：
```markdown
### 话题的"真正问题"是什么
[经过讨论，我们发现这个话题背后更深的命题是……]

### 哪些立场在讨论中被强化，哪些被削弱
[记录立场演变轨迹]
```

---

## Phase 5｜Writer 创作
与读书会工作流相同，参见 book-club.md Phase 5。

**话题讨论的写作建议**：
- Essay 模式：适合构建一篇"多元视角下的命题分析"
- Report 模式：适合输出"关于X话题的多维度洞见清单"
- 核心挑战：如何在呈现分歧的同时，提供超越分歧的洞见

## 快速模式（简化版）

如果话题相对简单，或只需要一轮快速分析，可使用简化模式：

```
快速模式：Phase 1（独立立论）→ Phase 2（主理人整合，仅提炼，不开启多轮对话）→ Phase 5（Writer 直接产出）
```

适用场景：
- 话题本身有明确答案，分歧不大
- 只需要多视角的快速盘点，不需要深度对话
- 时间/成本敏感
